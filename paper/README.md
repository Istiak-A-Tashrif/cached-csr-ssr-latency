# Paper

- `main.tex`, `main.pdf`: the manuscript, in ACM `acmart` (`acmsmall`, `review`, `nonacm`) for ACM Transactions on the Web.
- `refs.bib`: references. Each was verified against Crossref, USENIX, arXiv or the RFC Editor, and every DOI resolves.
- `numbers.tex`: every number the text states about the revision's analyses, generated by `make_numbers.py` from `testbed/results/revision/`. No result is typed by hand.
- `figs/`, `tables/`: generated by `make_figs.py` from the evaluation outputs in `testbed/results/`. `tables/ledger.tex` lists every model version and fresh test.
- `LITERATURE_SEARCH.md`: the search log (sources, queries, screening, results).
- `CLOSEST_WORK.md`: the closest-work comparison, with quoted passages.

Build:

```sh
python3 -m venv .venv && .venv/bin/pip install matplotlib==3.9.2 numpy==1.26.4
.venv/bin/python make_figs.py
python3 make_numbers.py
tectonic main.tex        # or: latexmk -pdf main.tex
```
